# DUKI WORLD

Proyecto integrador escolar de Nuevas Tecnologías (6.º año).

## Archivos
- `index.html`: estructura y contenido.
- `style.css`: diseño visual, efectos hover y adaptación responsive.
- `script.js`: modo claro/oscuro, menú móvil y trivia interactiva.

## Cómo probarlo
Abrir `index.html` en un navegador. Se necesita conexión a Internet para cargar Google Fonts y las imágenes ilustrativas externas.

## Publicarlo con GitHub Pages
1. Crear un repositorio público en GitHub, por ejemplo `duki-world`.
2. Subir los tres archivos (`index.html`, `style.css` y `script.js`) a la raíz del repositorio.
3. Entrar en Settings → Pages.
4. En Build and deployment, elegir Deploy from a branch.
5. Seleccionar la rama `main` y la carpeta `/ (root)`, y guardar.
6. Esperar a que GitHub Pages publique el sitio. La dirección aparecerá en esa misma sección.

## Nota
Las imágenes son ilustrativas y se cargan desde Unsplash. El contenido biográfico es una síntesis escolar. Verificar los datos y personalizar el proyecto antes de entregarlo.
